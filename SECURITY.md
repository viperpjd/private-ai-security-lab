# Security Policy

## Rules of engagement

1. Only run scans, tests or agents against systems listed in your signed scope file.
2. The lab range has no route to the internet or to production networks.
3. A human approves every action an AI tool takes against a system.
4. Never commit secrets. The pre-commit hook and CI both block them.

## Reporting a vulnerability

If you find a security issue in this repository, please open a private security advisory on
GitHub rather than a public issue. Include steps to reproduce and the affected file or tag.
